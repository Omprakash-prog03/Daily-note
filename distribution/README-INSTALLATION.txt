STUDENT OS — INSTALLATION GUIDE

APPLICATION: Student OS
VERSION: 1.0.0 (Code 1)
APPLICATION ID: com.studentos.studentos
DISTRIBUTION TYPE: Standalone Android APK (Debug Fallback - Sandbox Environment)

1. INSTALLATION
   - Download the APK file: StudentOS-v1.0.0.apk
   - Transfer to Android device (WhatsApp, Telegram, Google Drive, Bluetooth, etc.)
   - Open the file and tap "Install".
   - If prompted, enable "Install from unknown sources" in Chrome/Browser settings.

2. FIRST LAUNCH & ONBOARDING
   - Open "Student OS" from the app drawer or via deep link: studentos://main
   - Complete initial setup:
     * Name
     * College/University
     * Course/Department
     * Current Semester/Year
     * Attendance Threshold
     * Subjects
   - Data is stored locally (Room Database) and works offline.

3. CORE FEATURES (INDEPENDENT)
   - Attendance Management
   - Subject Management
   - Notes & Notebook
   - Assignment Manager
   - Timetable & Class Schedule
   - Examination Manager
   - Study Planner & Focus Tracker
   - Academic Performance Tracker
   - Calendar & Reminders
   - Student Profile & Settings

4. TECHNICAL SPECIFICATIONS
   - Application ID: com.studentos.studentos
   - Version Name: 1.0.0
   - Version Code: 1
   - Min SDK: 24 | Target SDK: 34
